# TG Channel Bot

Бот-редактор Telegram-канала про технологии и ИИ: собирает свежие новости из RSS, делает из них посты, присылает черновик с кнопками и публикует по расписанию.

Работает без внешних ИИ-сервисов: текст собирается из первоисточника алгоритмически (извлечение ключевых предложений + шаблоны форматов). Ключи API и локальные модели не нужны.

## Что умеет

- **Черновик с подтверждением** — пост приходит в личку, кнопки «Опубликовать», «Переписать», «Пропустить», «Удалить».
- **Автопостинг** — по слотам времени, если включён.
- **Контент-план** — на 7 дней вперёд, рубрики чередуются по дням недели.
- **Идеи тем** — 5 вариантов из свежих новостей.
- **Команды управления** — канал, расписание, статистика, очередь черновиков.
- **Дедупликация** — каждый источник используется один раз, новости кэшируются в SQLite.

## Установка

```powershell
cd C:\Users\Пользователь\Documents\tg-channel-bot
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
```

Заполни `.env`:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | твой Telegram ID (узнать: [@userinfobot](https://t.me/userinfobot)) |
| `CHANNEL_ID` | `@username` канала или `-100…` |
| `TZ` | часовой пояс слотов (по умолчанию системный) |

## Подготовка канала

1. Создай бота у @BotFather: `/newbot`, скопируй токен.
2. Добавь бота в канал **администратором** с правом «Публикация сообщений».
3. Запусти бота: `run.bat` или `.venv\Scripts\python.exe -m bot`.
4. Напиши боту `/start`, затем `/channel @твой_канал` — он проверит права.

## Команды

| Команда | Действие |
|---|---|
| `/post` | собрать черновик сейчас |
| `/digest` | дайджест из 3–4 новостей |
| `/auto on` / `/auto off` | автопубликация по слотам |
| `/schedule 10:00,15:00,19:00` | время публикаций |
| `/channel @name` | привязать канал |
| `/plan` | контент-план на неделю |
| `/ideas` | идеи тем |
| `/queue` | черновики в очереди |
| `/stats` | статистика и состояние |
| `/refresh` | подтянуть новости вручную |

## Как устроено

```
bot/
├── config.py      настройки из .env
├── sources.py     источники RSS + разбор ленты
├── generator.py   извлечение сути и сборка постов
├── actions.py     конвейер: новость → черновик → публикация
├── db.py          SQLite: новости, посты, настройки
├── keyboards.py   кнопки под черновиком
├── handlers.py    команды и callbacks
├── scheduler.py   слоты публикаций
└── __main__.py    запуск
```

Рубрики чередуются по дням: понедельник — новости, вторник — инструменты, среда — разбор, четверг — новости, пятница — дайджест, суббота — мнение, воскресенье — итоги.

## Ограничения

- Тексты не пересказываются «своими словами» языковой моделью: пост — это заголовок, 1–3 ключевых предложения источника и ссылка. Всегда указывается первоисточник.
- Англоязычные источники не подключены: перевода без LLM нет.
- Пост не «понимает» новость, поэтому рубрика выбирается по источнику и дню недели, а не по смыслу.
- Если нужен настоящий редакторский текст, движок заменяется на LLM: интерфейс `format_post()` в `generator.py` возвращает тот же словарь `{text, rubric, title, url, source}`, достаточно подставить вызов API.
